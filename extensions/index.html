Lotus

Lotus in your browser

Right-click a link and choose Download with Lotus DM, or open the toolbar popup to send the page you are on. The extension hands the link to the running app over 127.0.0.1 and the download joins the same queue as everything else. Nothing leaves your machine - there is no account and no server in the middle.

Windows only. The extension talks to the Lotus app on the same PC, so that app has to be open to accept a link. Android has no extension - share a link to Lotus DM from any browser instead.

Chrome, Edge, Brave, Opera

Chromium browsers need the folder once, then they keep it. It takes about a minute.

Download the extension .zip

  1. Unzip the file into a folder you will keep, for example Documents\Lotus-extension.
  2. Open chrome://extensions - in Edge that is edge://extensions.
  3. Turn on Developer mode (top right of that page).
  4. Click Load unpacked and pick the folder you unzipped.
  5. Pin Lotus to the toolbar from the puzzle-piece menu, so the icon is one click away.
  6. Start Lotus Download Manager, then click the Lotus icon: the badge should read connected.

Keep that folder where it is. If you move or delete it, the extension stops working and has to be loaded again. To update it later, replace the files inside the folder and press the reload arrow on the extension card.

If the badge says "app not running"

With Lotus Download Manager open, visit http://127.0.0.1:8460/ping in the same browser. You should see {"ok":true,...}.

  • No answer: the app is closed, or its bridge is switched off in Settings - Browser bridge.
  • Something else answers, or the port is busy: change the port in that same settings block, restart the app, then type the new port into the extension popup and press Save.

The extension asks for one host permission, http://127.0.0.1/*, and nothing else. It reads the tab you send and the link you right-click. No analytics, no remote code.
