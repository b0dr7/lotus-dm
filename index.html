Lotus Download Manager

Fast, free downloads for Windows and Android - multi-segment, resumable, and completely telemetry-free.

Windows 64-bit Windows 32-bit Android (universal)
Other Android devices
  • arm64-v8a - modern phones
  • armeabi-v7a - older or weaker phones
  • x86_64 - emulators and Chromebooks

Features

Multi-segment

Eight parallel connections per file for maximum speed.

Resume

Pause, resume, and pick up after a restart exactly where you stopped.

Speed limits

Per-download and global throttles when you need the bandwidth back.

Clipboard monitor

Catch copied links automatically - optional, off by default.

Browser integration

Send downloads from Firefox and Chrome straight to the queue.

No tracking

Zero telemetry, zero ads, zero webviews. Entirely free.

Install

Windows

  1. Download the 64-bit build (or 32-bit for older PCs).
  2. Run the downloaded .exe file.
  3. Paste a URL - your first download starts.

Android

  1. Download the universal APK (or your device's build under Other Android devices).
  2. Allow installs from your browser when prompted.
  3. Open the downloaded APK and confirm the install.
